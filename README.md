Fineco Credit Lombard Cost & Leverage Calculator
An interactive, user-friendly financial web application designed to calculate the total borrowing costs and net arbitrage returns of Fineco Bank’s Credit Lombard (pawn credit / lombard loan) facility.
🌟 Key Features
 * Dynamic Interest Rate Engine (TAN):
   * Auto-calculates borrowing costs based on the current 3-month Euribor (360-day base convention).
   * Pre-configured client tiers:
     * Standard: Euribor + 1.00%
     * Private Banking: Euribor + 0.50%
     * Promotional / Custom: Custom spread entry (e.g., Euribor + 0.10%).
 * Flexible Duration Modes:
   * Calculate costs by exact Number of Days, Months, or specific Calendar Dates (Start & End dates).
 * Investment Leverage & Arbitrage Analysis:
   * Simulate reinvesting borrowed capital into yield-generating assets (e.g., bonds, ETFs, dividend stocks).
   * Calculates gross return, capital gains tax, net investment income, and final net profit/loss.
 * Tier Cost Comparison Table:
   * Side-by-side breakdown comparing total interest and effective cost across Standard, Private, and Promo accounts.
 * Interactive Visualizations:
   * Visual timeline charts powered by Chart.js tracking principal debt vs. cumulative interest over time.
 * Fineco Settlement Rules Notice:
   * Displays specific bank settlement schedules (annual settlement in March) and zero-cost unused line-of-credit reminders.
🛠️ Built With
 * HTML5 / CSS3: Responsive UI designed with modern CSS components and tailored Fineco-inspired styling.
 * JavaScript (Vanilla ES6): Client-side calculations without external heavy frameworks.
 * Chart.js: Dynamic, responsive interactive charts.
